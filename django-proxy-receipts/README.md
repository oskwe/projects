# Акты оприходования материальных ценностей и доверенности

> **Стек:** Python 3.13 · Django 6 · PostgreSQL / SQLite · Materialize CSS · 19 автотестов
>
> Веб-приложение для ведения двух первичных документов (доверенность и акт оприходования по форме М-35) со справочниками, печатными формами, расчётами и суммой прописью.


Учебный проект на Django, сделанный по методическим указаниям «Создание веб-интерфейса документа „Доверенность“ (Django + PostgreSQL)». Устроен так же, как пример «Лист тракториста-машиниста». В одном приложении работают два документа:

- **Акт об оприходовании материальных ценностей**, полученных при разборке и демонтаже зданий и сооружений. Состав реквизитов и граф взят из унифицированной формы № М-35. Главная страница открывает журнал актов.
- **Доверенность** — документ из методички со справочниками и печатной формой.

## Быстрый запуск в Windows

1. Склонируйте репозиторий: `git clone` (или скачайте ZIP через кнопку Code → Download ZIP и распакуйте).
2. Установите Python 3.12 или новее. Зависимости установятся из PyPI автоматически.
3. Дважды щёлкните `START.bat`. При первом запуске создаётся окружение `.venv`, устанавливаются зависимости, применяются миграции, добавляется демонстрационный пример и открывается браузер.
4. Адрес программы: http://127.0.0.1:8000/ . Окно терминала не закрывайте. Чтобы остановить сервер, нажмите Ctrl+C.

Ручной запуск из папки проекта (как в методичке):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

## Структура (по методичке)

| Приложение | Назначение |
|---|---|
| `accounts` | справочник счетов |
| `customers` | контрагенты (в акте — **подрядчик**) |
| `departments` | отделы (в акте — **структурное подразделение**) |
| `employees` | сотрудники (комиссия, кладовщик, получатель доверенности) |
| `organizations` | организации (в акте — **заказчик**); добавлены ОКПО и ИНН |
| `positions` | должности |
| `products` | товары (в акте — **материальные ценности**); добавлен номенклатурный номер |
| `units` | единицы измерения; добавлен код по ОКЕИ |
| `warehouses` | **новый справочник складов** с кладовщиком (аналог «Техники» в примере) |

У каждого справочника есть страницы `list`, `create`, `edit`, `delete`. Их можно зарегистрировать в админке `/admin/`: учётная запись создаётся командой `manage.py createsuperuser`.

## Работа с актом оприходования

1. Заполните справочники: организации, контрагенты, сотрудники, склады, единицы измерения, товары. Команда `seed_demo` уже добавила вымышленный пример.
2. Меню «Документы» → «Акты оприходования материальных ценностей» → **Добавить**.
3. Заполните реквизиты: номер, дату, организацию-заказчика, подрядчика, объект разборки, склад, основание и комиссию.
4. Кнопкой **«Добавить позицию»** добавляются строки. Для каждой укажите материальную ценность, количество, процент годности и при необходимости цену. Если цена пустая, берётся цена из справочника товаров. Сумма по строке и итог акта пересчитываются сразу при вводе.
5. Флажок **«Удалить позицию при сохранении»** исключает строку. В акте должна остаться хотя бы одна позиция.
6. Кнопки: **Создать/Сохранить**, **Сохранить и печать** (зелёная кнопка с принтером) и **Отмена**.

Кнопки в журнале: просмотр, печатная форма, изменение, **копия** (новый акт с теми же реквизитами и строками), удаление с подтверждением. В журнале есть поиск по номеру, организации, подрядчику и объекту, а также постраничный вывод.

### Расчёты (на сервере, десятичная арифметика)

- Графа 9 «Количество, принятое к учёту» = графа 7 × процент годности / 100 (округление до 0,001).
- Графа 11 «Сумма» = графа 9 × цена (округление до копеек).
- Итог акта — сумма графы 11. Он выводится также **прописью** («Пятьдесят семь тысяч сто рублей 00 копеек»).
- Количества складываются, только если все позиции в одной единице измерения. Иначе в итоговой строке ставится «×».

Учебный пример: кирпич 2500 шт × 80 % = 2000 шт × 9,50 = 19 000,00; металлолом 1,25 т × 18 000 = 22 500,00; доска 3,2 м³ × 75 % = 2,4 м³ × 6 500 = 15 600,00. **Итого 57 100,00 руб.**

### Проверки

- Номер акта уникален для организации и даты составления.
- Дата утверждения не может быть раньше даты составления.
- Председатель и члены комиссии — разные люди.
- Количество больше нуля, процент годности от 0,01 до 100, цена не отрицательная.
- Одинаковые строки (тот же товар, сорт, годность и цена) нужно объединить.
- Если кладовщик не выбран, берётся кладовщик склада. Если на складе его нет, программа попросит указать кладовщика.
- Заголовок и строки сохраняются одной транзакцией: при ошибке в строке ничего не записывается.
- Справочник, который используется в документе, удалить нельзя. Программа покажет сообщение.
- Реквизиты справочников сохраняются в акте снимком. Если позже переименовать организацию или товар, уже созданный акт не изменится.

## Печатная форма

«Просмотр» → **«Печать / PDF»**. Печатная форма открывается на чистом белом листе без меню. Под документом три кнопки (на бумагу они не выводятся):

- **Печать** — открывает окно печати браузера. Там же можно выбрать «Сохранить как PDF». Настройки: **A4, альбомная ориентация, масштаб 100 %, колонтитулы браузера выключены**.
- **Назад** — возвращает к просмотру акта.
- **Сохранить** — скачивает документ файлом `Акт_оприходования_№…_от_….html`. Файл открывается в любом браузере без запуска программы и выглядит так же, как на экране.

Акт с несколькими позициями помещается на один лист. При большом числе строк таблица продолжается на следующем листе, и её шапка повторяется. Места «М.П.» оставлены пустыми: печать ставится на бумаге вручную.

На печатной форме:

- шапка формы М-35 (ОКУД 0315006, ОКПО, вид деятельности, вид операции), блок «УТВЕРЖДАЮ» и таблица «Номер документа / Дата составления»;
- таблица из 12 граф с номерами граф, итоговой строкой и суммой прописью;
- подписи председателя и членов комиссии, представителя подрядчика и кладовщика.

## Навигация

- Боковое меню: заголовок **«Документы»** (это кнопка, она открывает журнал доверенностей), ниже пункты **Доверенности** и **Акты оприходования материальных ценностей**.
- Верхняя панель: выпадающий список **«Справочники»** со всеми справочниками.
- Главная страница `/` — журнал актов оприходования.

## PostgreSQL по методичке

Без настроек проект работает на SQLite (`db.sqlite3`). Так его можно запустить на любом компьютере. Чтобы подключить PostgreSQL:

1. В pgAdmin 4 создайте базу **`crm_akt`**.
2. Скопируйте `database.local.example.json` в `database.local.json` и укажите своего пользователя и пароль PostgreSQL.
3. Выполните:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Можно обойтись без файла и задать переменные окружения `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_HOST`, `POSTGRES_PORT`. Таблицы появятся в pgAdmin: `crm_akt` → Schemas → public → Tables. Не включайте `database.local.json` с паролем в архивы.

## Основание печатной формы

Состав реквизитов и граф соответствует унифицированной форме № М-35 «Акт об оприходовании материальных ценностей, полученных при разборке и демонтаже зданий и сооружений» (постановление Госкомстата России от 30.10.1997 № 71а). Ширина колонок адаптирована под A4. Проект учебный: для реального учёта организация утверждает применяемую форму сама. Все данные примера вымышлены.
