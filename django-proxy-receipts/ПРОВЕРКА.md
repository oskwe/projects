# Результаты проверки

Дата: 30 сентября 2026 года. Python 3.13, Django 6.0.6.

- `manage.py check`: ошибок нет.
- `makemigrations --check --dry-run`: несохранённых изменений схемы нет.
- 19 автоматических тестов прошли на SQLite (`receipts/tests.py`, `proxies/tests.py`). Проверены расчёты, сумма прописью, создание, изменение, копирование и удаление акта, добавление и удаление строк, кнопка «Сохранить и печать», ошибки ввода без частичного сохранения, уникальность номера, разные члены комиссии, кладовщик по складу, снимок реквизитов, защита справочников от удаления, CSRF, CRUD всех справочников и доверенности.
- Все страницы (журналы, формы, печатные формы, справочники, админка) открываются с кодом 200.
- В браузере Chromium пройден сценарий: создание акта, выбор склада с автоподстановкой кладовщика, добавление позиции с пересчётом суммы на лету, пометка строки на удаление, «Сохранить и печать», кнопки «Печать», «Назад» и «Сохранить» под печатной формой. Ошибок JavaScript нет.
- Печать в PDF (A4, альбомная ориентация): акт из 3 позиций помещается на 1 лист. Акт из 26 позиций занял 3 листа, шапка таблицы повторяется, итоги и подписи выведены один раз.
- Доверенность: создание, изменение, печатная форма с оттиском печати.

На PostgreSQL проект здесь не запускался: драйвер `psycopg` недоступен в среде проверки. Модели и миграции стандартные для Django. Настройка PostgreSQL описана в README; пакет для Windows / Python 3.13 лежит в `wheels`. Физическая печать на принтере не проверялась.
