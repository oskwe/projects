# Основы веб-разработки: HTML, CSS, JavaScript, Nginx

> **Стек:** HTML5 · CSS3 · JavaScript (ES6) · Nginx · Docker Compose

Лабораторные работы № 1–6 по основам веб-разработки.

| Лаба | Темы |
|---|---|
| 1 | Разметка HTML, таблицы, списки, изображения, CSS-фреймворк Pico |
| 2 | Настройка Nginx: защищённые разделы, страницы ошибок, редиректы |
| 3 | Вёрстка и стили CSS |
| 4 | JavaScript: банковская карта, часы, секундомер, дата и время, проверка надёжности пароля |
| 5 | Формы и клиентская валидация |
| 6 | Интерактивные страницы на JavaScript |

## Запуск

```bash
docker compose -f docker-compose-local.yml up
```

Затем откройте http://localhost (страница со списком всех лабораторных).

Примечание: в lab1/task8–9 используется CSS-фреймворк Pico; его файлы не включены в репозиторий, их можно подключить с CDN.
