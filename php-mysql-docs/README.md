# Документы «Доверенность» и «Ведомость» на PHP + MySQL

> **Стек:** PHP 8.2 · PDO · MySQL 8 · Apache · Docker Compose · phpMyAdmin

Учебное веб-приложение без фреймворков: справочники (счета, контрагенты, сотрудники, организации, товары, единицы измерения), документы «Доверенность» и «Ведомость» с печатными формами. Все запросы к БД выполняются через подготовленные выражения PDO.

## Запуск

```bash
docker compose up --build
```

Приложение: http://localhost:8080/src/proxy/proxy_view.php, phpMyAdmin: http://localhost:8081.

Пароли в `docker-compose.yml` и `config.php` — учебные значения для локального контейнера.
